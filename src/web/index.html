First-time local setup

Ollama (recommended): download Ollama for Windows, open the app, and allow it to finish setup.

In PowerShell, explicitly download a model you choose with ollama pull <model-name>, then list installed models with ollama list. Nox never downloads model weights for you.

Use provider Ollama, endpoint http://127.0.0.1:11434, and select the exact installed model name returned by Discover.

LM Studio: install LM Studio, download/load a model in the app, then open Developer and start its local server. Default endpoint: http://127.0.0.1:1234/v1. Use Discover for its model ID.

llama.cpp: start a compatible local server bound to 127.0.0.1; see the official server documentation for build and model requirements.

For remote endpoints, Nox requires the explicit opt-in below. Local models need no cloud account.
